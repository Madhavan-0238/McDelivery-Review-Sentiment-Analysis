# McDelivery-Review-Sentiment-Analysis
This project was developed during my Data Analyst internship to analyze customer feedback from McDelivery orders using Natural Language Processing (NLP) and Machine Learning. The objective was to extract meaningful insights from customer reviews, identify sentiment trends that could help improve customer satisfaction and operational efficiency.

🍂FEATURES

Data preprocessing and cleaning

Text normalization using NLP techniques

Sentiment analysis (Positive, Neutral, Negative)

Word cloud generation for frequent terms

Sentiment distribution visualization

Theme and keyword analysis

Machine Learning-based sentiment classification

Performance evaluation using classification metrics
